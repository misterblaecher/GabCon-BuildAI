# GabCon Build Prompts

These prompts define the visual direction and individual modules for the GabCon steampunk fantasy valley.

Use `00-master-style.txt` as a shared style guide for every build.

Recommended generation order:
1. central portal
2. railway viaduct
3. observatory
4. cliffside factory
5. arcane complex
6. waterfront city
7. mountain castle

The large terrain, lake and mountains are intentionally excluded from individual prompts and should be built separately.
