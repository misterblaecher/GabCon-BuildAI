Une idée. Deux chemins.

Avec ChatGPT, crée directement un fichier Minecraft. Avec GabCon BuildAI, génère et prévisualise un blueprint grâce au moteur installé sur ton PC. Ces deux parcours sont indépendants.

PARCOURS A · GÉNÉRATION DIRECTE AVEC CHATGPT

ChatGPT crée ton fichier Minecraft

Choisis un format par bouton, copie le prompt et récupère le vrai fichier dans ChatGPT. Aucun passage par le moteur BuildAI.

DEUX PARCOURS / A + B
Choisis comment créer ton build.
A — ChatGPT direct : la sélection de format prépare un prompt ; ChatGPT crée le fichier à télécharger et à tester dans Minecraft. Aucun moteur BuildAI nécessaire. Les formats ChatGPT ne modifient jamais les réglages du moteur. Utilise uniquement du code de confiance.
