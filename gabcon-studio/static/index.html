Connecte ton PC et ton téléphone au même réseau privé Tailscale, puis ouvre l'adresse HTTPS donnée par tailscale serve status sur ton téléphone. Tu peux ensuite ajouter GabCon Studio à l'écran d'accueil. Ton PC doit rester allumé pendant les constructions.

          

          
        

        
HOW IT WORKS / 04
Une idée. Du code. Des blocs.
Dans cette version, ChatGPT sert uniquement à écrire le blueprint. Aucune connexion à l'API OpenAI n'est utilisée. BuildAI exécute ensuite le code dans son environnement Python local, génère les vues et produit un schematic WorldEdit. Utilise uniquement du code provenant d'une source de confiance.
